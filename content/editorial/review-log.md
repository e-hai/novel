# Human Editorial Review Log

This log records the human review gate required before any chapter is published. Per the project compliance plan, a chapter may not go live without an entry here. Keep this file updated as chapters are edited.

## How to use

For each chapter, the human editor records:
- **Status:** `draft` → `in-review` → `approved`
- **Substantive changes made:** what was actually rewritten (not just proofread)
- **Date and reviewer**

A chapter marked `draft` or `in-review` is excluded from the generated site by the generator. Only `approved` chapters are published.

## Note to the human editor

The prose in `content/chapters/` is an **AI draft**, not a finished work. Before marking any chapter `approved`:

1. Read it aloud. Rewrite sentences that don't sound like you.
2. Check character and world consistency against the world bible.
3. Make substantive changes — not synonym swaps (obfuscation is a policy violation).
4. Record what you actually changed above.
5. Only then set `status: approved` in the chapter's front matter and tick the box.

Until that happens, the generator will hold these chapters back. That gate is deliberate.
