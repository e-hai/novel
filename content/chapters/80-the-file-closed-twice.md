# The File Closed Twice

Entry 80 — 3 February. The file was closed on the third, for the second time, with the shop's appendix attached and the nine questions attached and the proposal attached.

Four documents, one man, one room with a door and a person at it, and no finding that anybody can check. The board's closing note uses the word satisfactory twice, which is what an office writes when it has decided that the alternative is an inquiry.

I wrote the last page of Part XI myself, and it is the only page in this book that is addressed to a reader rather than to the shop: if you are reading this in fifty years, the file was closed twice, the person at the door was never named, and the shop kept both copies.

Mara signed under it because the rule requires a second hand on every entry that is a decision. She read it first. She said: it is a record and not an accusation. That is the distinction the whole trade lives inside and the reason the book is legible.

End of Part XI. Four documents, nine questions, one unopened letter, and a file closed twice.
