# Running It Twice

Entry 61 — 19 September. The loom can hold a viewpoint, not a person. Running it twice is not twice the work; it is a different trade.

The first thing you learn is that two accounts do not agree about a room, ever, and that the disagreement is not damage. One remembers the window open, one remembers it shut, and both are correct, because one arrived a minute earlier.

The second thing is that the loom has to be told which account holds the frame. There is no neutral setting. Whoever holds the frame gets a repair that fits their room, and the other account gets a repair that fits a room they were in.

Mara ran the first test alone, on two cores belonging to nobody, and the result was a third memory that neither account recognised. She wrote it up as a failure and the Ward has not been told, because the rule says two hands and says nothing about what the two hands produce.
