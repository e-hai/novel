# Ader 嘅檔案

紀錄 71 — 11 月 28 日。董事會寄嚟一份檔案，附一句：作為被審一方審閱。

Ader 督察為咗寫得出第 12/2026 號發現，修咗自己個疑問。佢做得合法——審查員可以修自己嘅疑問，前提係紀錄要畀被審一方睇——而紀錄真係畀人睇咗；而家董事會想要舖頭對結果嘅意見。

二百一十一頁。同一場審計嘅三個帳，喺三間舖影，其中一間係呢間。第三個帳有一個接駁，頭兩個冇。第 84 頁有佢自己手寫一句：我唔記得寫過呢頁，而我照簽。

呢行我讀過好多核，從來冇讀過一份咁明白係一份有牌照號碼嘅自白。

Mara 一口氣讀完，話：呢個就係條規矩落到寫規矩嗰個人身上嘅樣。我抄低，然後喺頂寫日期——呢個係辦事處嘅規矩，而我已經唔再覺得好笑。
