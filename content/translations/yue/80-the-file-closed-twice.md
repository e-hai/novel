# 檔案閉兩次

紀錄 80 — 2 月 3 日。檔案 3 號閉檔，第二次；舖頭附錄、九條問題、建議書都附住。

四份文件、一個男人、一間有門有企住一個人嘅房，而冇一個發現查得到。董事會閉檔附註用咗兩次「滿意」——一個辦事處決定另一個選擇係調查嗰陣，就會咁寫。

第十一部最後一頁我自己寫，亦係本書唯一一頁寫畀讀者、唔係寫畀舖頭：如果你喺五十年後讀到呢句——份檔案閉咗兩次，門口嗰個人從來冇名，而舖頭兩份副本都留住。

Mara 喺下面簽，因為規矩要求每一條係決定嘅紀錄都要第二隻手。佢先讀。佢話：呢個係紀錄，唔係指控。呢個就係成套行業活喺入面嘅分別，亦係本書讀得通嘅原因。

第十一部完。四份文件、九條問題、一封未拆嘅信、一份閉咗兩次嘅檔案。
